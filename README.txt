КИПиА — инженерный помощник (PWA)

Установка на GitHub Pages:
1. Создайте репозиторий.
2. Загрузите содержимое архива в корень репозитория: index.html, manifest.json, sw.js, папку icons.
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Откройте опубликованный HTTPS-адрес на телефоне и добавьте на экран «Домой».

Обновление:
- При каждом изменении приложения увеличивайте CACHE в sw.js (например, kip-assistant-v1 -> kip-assistant-v2).
- Service worker кеширует приложение для офлайн-работы после первого успешного открытия.

Важно:
- Инструмент предназначен для инженерных оценок и оперативных расчётов, а не заменяет паспорта, методики поверки, таблицы НСХ и нормативные документы.
- Расчёт термопары K в этой версии приближённый.
- SMD-маркировки неоднозначны между производителями. Проверяйте datasheet.
- Расчёт расхода Q=K*sqrt(dP) требует индивидуального коэффициента K.
- В расчёте сопротивления кабеля используется удельное сопротивление при 20 °C.
