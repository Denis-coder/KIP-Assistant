КИП КОНВЕРТЕР — инженерный помощник (обновлённая версия)
========================================================

Публикация на GitHub Pages
--------------------------
1. Распакуйте архив.
2. Загрузите СОДЕРЖИМОЕ архива в корень репозитория (index.html, manifest.json,
   sw.js, README.txt и папку icons). Не загружайте папку kip-konverter-v6 целиком.
3. GitHub: Settings -> Pages -> Deploy from a branch -> выберите main и /(root).
4. Откройте адрес GitHub Pages. Приложение работает без внешних библиотек и API.

Обновление после публикации
---------------------------
В sw.js используется новый кеш kip-v6. После публикации закройте старую вкладку
приложения и откройте сайт заново. Если браузер продолжает показывать старую
версию, выполните полную перезагрузку страницы или очистите данные сайта.

Разделы и инструменты
---------------------
• Давление: перевод Па, кПа, МПа, бар, мбар, атм, мм рт. ст., мм вод. ст.,
  кгс/см², psi, inHg, inH₂O; гидростатический уровень по P = ρ·g·h.
• Температура: °C, °F, K, °R; Pt100/Pt500/Pt1000 по IEC 60751 в диапазоне
  −200…+850 °C, расчёт в обе стороны.
• Расход: объёмный и массовый расход; оценочный расчёт Q = K·√ΔP.
• Электрика: напряжение, ток, сопротивление, мощность, частота; расчёт
  активной/полной/реактивной мощности симметричной трёхфазной нагрузки.
• Цепи: последовательное и параллельное соединение R/C/L; делитель напряжения
  с учётом входной нагрузки; резистор светодиода и ближайший E24; RC-цепь;
  падение напряжения на двухпроводной линии.
• Прочее: линейное масштабирование 4–20 мА, индикация выходов NAMUR NE43,
  проверка запаса напряжения токовой петли, абсолютная/относительная/
  приведённая погрешность, длина, масса, объём, плотность.
• Номиналы: цветовая маркировка резисторов (4/5 полос), SMD-коды (3/4 цифры,
  R-десятичная точка, EIA-96), маркировка конденсаторов и катушек.

Важные ограничения
------------------
• Q = K·√ΔP — упрощённая зависимость. K должен быть получен из расчёта,
  паспорта или градуировочной характеристики конкретного узла. Это не
  универсальный расчёт диафрагмы по ISO 5167.
• Трёхфазная мощность рассчитана для симметричной нагрузки и линейных U/I.
• Падение на кабеле — оценка по удельному сопротивлению при 20 °C; не учитывает
  реактивность, переходные сопротивления и нагрев жил.
• Проверка токовой петли не включает автоматически барьеры, изоляторы,
  защитные элементы и требования конкретного преобразователя.
• Цветовые и буквенно-цифровые коды зависят от стандарта и производителя.
  Если маркировка неоднозначна, сверяйте её с документацией компонента.
• Приложение — инженерный калькулятор, а не замена поверки, паспорта,
  проектного расчёта или требований промышленной безопасности.

Все вычисления выполняются локально в браузере. Данные никуда не отправляются.
